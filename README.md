# FlappyBird-OpenGL
A flappy bird clone written in c++ and opengl.

### What this is currently
Well, not much. Currently, all there is to the external side of things is a window that draws a flat background.

Internally, things are a bit more interesting. I have the _beginning_ of a shader class, the _beginning_ of a player class, a color conversion function that will be very useful later on, and some other minor things.

### Plans
**Note: This project will not contain text. My next project might be a full text rendering engine, but until I learn some more about how text rendering works, I won't implement it in any OpenGL projects.*

I hope to add textures, an actual player, a pipe generating algorithm, and some other required things. This project was never planned to be the most polished of games :) , just a learning excersize.

## Running

You can find the builds [here!](https://github.com/ofer-afik/FlappyBird-OpenGL/releases/tag/v0.1.0)

**Note for Windows and MacOS - I haven't had a chance to test these builds! If you find an error, you're more than welcome to share it, and I'll do my best to solve it.*

### Windows
Download and run the .exe! If your OS tells you that it is blocked because of security issues, try clicking the "More Info" link, and that should reveal a "Run Anyways" button.

**Note: see earlier*

### MacOS
Run the executable. You might need to enable "Executable as program" - in the file browser, right click the file, and you should have a submenu in which you can enable it.

**Note: see earlier*

### Linux
Run the executable. You might need to enable "Executable as program" - in the file browser, right click the file, and you should have a submenu called "Properties" in which you can enable it.
