# FlappyBird-OpenGL
A flappy bird clone written in c++ and opengl.

### What this is currently
Well, not much. Currently, all there is to the external side of things is a window that draws a flat background.

Internally, things are a bit more interesting. I have the _beginning_ of a shader class, the _beginning_ of a player class, a color conversion function that will be very useful later on, and some other minor things.

### Plans
**Note: This project will not contain text. My next project might be a full text rendering engine, but until I learn some more about how text rendering works, I won't implement it in any OpenGL projects.*

I hope to add textures, an actual player, a pipe generating algorithm, and some other required things. This project was never planned to be the most polished of games :) , just a learning excersize.
